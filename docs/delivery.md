# Phase gates
The build proceeds in the supplied phase order. A phase is checked off only with evidence. Current APK build and emulator evidence are linked in docs/qa.md; tagged phase checkpoints preserve a fallback.

Synthetic records are local to the demonstration. Resident and officer personas are a role selector, not authenticated identities. All edits persist on the current device only.

Optional scope cut order: OC4IDS, native share, location and comments; release signing; local follow/delay entry; new-permit form; sequence suggestions. Core clash rules, street/project screens, validation, APK, back handling, offline launch, hosting and recorded APK demo stay required.
