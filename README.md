# Works Registry
Android app (APK) and hosted companion for a synthetic Chennai public-works demo. Under active construction; no claim of government deployment.
See PRODUCT.md for the product brief and docs/decisions.md for routine decisions. Build plan and supplied research remain private. APK uses Capacitor 8 and Android System WebView. Minimum Android: 7.0 (API 24).
Development: npm ci, npm run dev, npm test, npm run build. Android: npm run android:apk (JDK 21 and SDK 36) or download the GitHub Actions artifact.
Synthetic demonstration works; geometry and rule evidence are disclosed in About. No backend, real authentication or service worker.
